# 二度目のごはん

### 思い出ごはん再現屋・朔と清一

## あらすじ

港町・鵜崎の古い商店街の路地に、看板を出していない食堂がある。硝子戸に貼り紙が一枚だけ。「思い出のごはん、もう一度お作りします 一食三千円 材料費別」。作るのは凪本朔、二十七歳。口をきくのが苦手で、笑い方も下手で、そのかわり舌だけが異常に利く。一口食べれば材料も手順も分解できる——ただし、目の前に一皿あるときだけだ。誰かの記憶の中にある味は、食べられないから分からない。だから、この商売にはもうひとり要る。聞き役の田川清一、五十四歳。廃刊した地方紙で四十年近く人の話を聞いてきた男が、依頼人の記憶を、味の手がかりに変えていく。肉の入っていないハンバーグ、味のしない人の好物、まっ黄色の卵焼き、海を渡ってきた豆の汁。一話に一件、二人は誰かの「もう一度」を作りにいく。そして朔にも、どうしても再現できない一杯がある。親のない自分を育てた食堂の女将・トメが、夕方になると出してくれた汁。トメはいま施設にいて、記憶がまばらだ。同じ味を作ろうとするたび、朔は届かない。届かない理由が分かるまでに、十件かかった。作り方を思い出す、温かい人情連作。

- 第03話「まっ黄色の卵焼き」
- 第04話「海を渡ってきた鍋」
- 第05話「みなと食堂の焼きめし」
- 第06話「継げない味」
- 第07話「もう一度は作れない」
- 第08話「書かなかった一行」
- 第09話「おいしいね」
- 第10話（最終話）「二度目のごはん」

## 登場人物

- **凪本朔（なぎもと さく）** — 主人公のひとり。二十七歳。看板のない食堂の料理人。無口で無愛想、感情が料理にしか出ない。舌が異常に利き、一口食べれば材料と手順を分解できるが、**それは目の前に一皿あるときだけ**で、人の記憶の中の味は分からない。親がなく、商店街の「みなと食堂」に住み込みで育てられた。
- **田川清一（たがわ せいいち）** — 主人公のひとり。五十四歳。廃刊した地方紙「鵜崎日日新聞」の元記者。生活面で四十年近く市井の話を聞いてきた。愛想と段取りと聞き取りは全部この人。かつて、みなと食堂の閉店記事を書いた。
- **佐々木トメ（ささき トメ）** — 「みなと食堂」の元女将。八十三歳。朔の育ての親。いまは施設で暮らし、記憶がまばら。何を食べても「おいしいね」と言う。
- **梅本きよ** — 商店街の乾物屋の女主人。八十歳近い。トメの古い友人で、二人の商売のいちばんの宣伝係。
- **中原孝之** — 第01話の依頼人。転勤で町を出る五十代。子どもの頃通った洋食屋のハンバーグを探している。
- **岸うみ** — 第03話の依頼人。小学四年生。小遣いを握って「母さんの卵焼き」を頼みに来る。

## 制作メモ

- ジャンル：食・料理もの（本プロジェクト初）／主人公：二人組のバディ（初）／メイン軸：一話=一件の連作+縦糸／トーン：ほのぼの人情・温かい結末／全10話。
- **先に固定した規則**：朔の舌は「目の前の一皿を分解する」能力で、記憶や説明からは味を導けない。だから聞き役の清一が必要で、だから自分の記憶にあるトメの汁は再現できない。この線を第01話で明示しておかないと、最終話が後付けの言い訳に見える。
- 縦軸は「名前のない一杯」ではなく「**同じ味が二度ない一杯**」。答えは、あの汁がその日の店の残りで作られていた=毎日ちがった、というもの。再現とは同じ味を作ることではなく、同じ作り方をすること。第07話「死んだ人の味は作れるが、その人にはならない」で先に一度この考えを鳴らしておく。
- 既存作『さよならの部屋』と骨格（出向く専門職の連作+親代わりの縦糸+第5・8・9話で手がかり）が近いので、あちらの「証拠は全て遺品」に対して本作は「**決定的な手がかりは必ず五感**（味・匂い・食べ方・鍋の焦げ跡）」で統一した。清一の取材ノートは答えではなく「どこを見るか」しか示さない。
- 分量・温度は漢数字と日本語表記に統一（大さじ二／二百グラム／百六十度）。既存作の反省どおり、単位記号は英字混入の温床。

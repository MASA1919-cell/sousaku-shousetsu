# 回覧板、まわします

### 柚木町三丁目四班・一年だけの班長

## あらすじ

三月末、七年勤めた派遣の仕事が「契約満了」で終わった。小野寺ひより、三十一歳。資格なし、貯金わずか、恋人なし、特技なし。昔から仕事が遅く、職場では「小野寺さんは、おそい」と言われてきた。行くあてのない彼女に、腰の骨を折った祖母・サトが電話で言う。「うちの家、春に売るまで住んどいて。ついでに班長、頼むわ」。坂の町・柚木町三丁目四班。祖母が引き当ててしまった町内会の班長は、回覧板を六軒に回す役目だった。いちばん古株の嶋田フミは言う。「回覧板はね、手で渡して、一言そえるの」。けれど回覧板の最後の家、畳屋の久住さんだけは、いつも留守だ。戻ってきた回覧板の確認印の下に、鉛筆書きの付箋が一枚貼ってある。『お疲れさまです。四班は回るのに三日かかります。久住』。返事を書いて貼ったのが始まりだった。ごみ当番、どぶ掃除、夏祭りの提灯、台風の夜。月にひとつの回覧と、付箋一枚ぶんずつ近づいていく二人。言葉がつかえる畳職人と、何も持っていないけれど、人の言葉を最後まで待つことだけはできる女。一年だけのはずの班長の、春から春までの話。

## 目次

- 第01話「班長くじ」
- 第02話「ごみ当番表」
- 第03話「どぶ掃除の朝」
- 第04話「提灯の名前」
- 第05話「迎え火」
- 第06話「台風の夜」
- 第07話「下宿の灯り」
- 第08話「畳を替える」
- 第09話「火の用心」
- 第10話（最終話）「回覧板、まわします」

## 登場人物

- **小野寺ひより（おのでら ひより）** — 主人公。三十一歳。都内の物流会社で派遣事務を七年、三月末で契約満了。資格も特技もなく、何をやっても人より遅い。そのかわり、人の話を途中で取らない。相手が言い終わるまで、ただ待っている。祖母の家の留守番と、町内会の班長を一年だけ引き受ける。
- **久住恭介（くずみ きょうすけ）** — 三十四歳。坂の下の「久住畳店」の三代目。腕はいいが、子どもの頃から吃音があり、言葉の頭がつかえる。自分の名字がいちばん言いにくい。だから回覧板には、鉛筆の付箋で話す。
- **久住茂（くずみ しげる）** — 六十六歳。恭介の父。二代目。町内会の副会長で、声が大きく、口が早い。息子の言葉を先に言ってしまう癖がある。
- **嶋田フミ（しまだ ふみ）** — 八十六歳。四班の最古参。班長を九回やった。「回覧板は手で渡して、一言そえる」が信条。サトとは五十年来の友人。
- **小野寺サト（おのでら さと）** — ひよりの祖母。八十四歳。三月はじめの班長くじで班長を引き当て、その月のうちに転んで腰の骨を折った。いまは県庁所在地の娘（ひよりの母）のマンションに身を寄せ、電話口では誰より元気。家は春に売るつもりでいる。
- **葉山千尋（はやま ちひろ）／葉山大地（はやま だいち）** — 四班の共働き家庭。千尋は市民病院の看護師で夜勤がある。大地は六歳の年長さん。ひよりを「はんちょう」と呼ぶ。
- **篠原正道（しのはら まさみち）** — 七十二歳。元中学校の国語教師。三年前に妻の和子を亡くして以来、町内の行事に一度も出てこない。字がとても上手い。
- **三浦拓海（みうら たくみ）** — 十九歳。大学一年。四班のアパート「柚木荘」の二階に下宿している。
- **大橋（おおはし）** — 柚木町三丁目の町内会長。七十代。会議が長い。
- **宮内（みやうち）** — ひよりの元派遣先の課長。

## 制作メモ

- ジャンル：現代恋愛（恋愛を主軸にした現代日本ものは本プロジェクト初。恋愛要素自体は『静かの海郵便局』にあり）／主人公：何も持たない凡人／メイン軸：人情×ほのぼの／結末：ハッピーエンド／全10話。
- **先に固定した規則**：
  - 回覧の順は「小野寺→嶋田→葉山→篠原→柚木荘→久住→小野寺」。久住が最後の家なので、戻ってきた回覧板のいちばん上には必ず恭介の付箋がある。これが二人の連絡路で、第01話で明示する。
  - 恭介は吃音で、とくに自分の名字（く）と、か行・た行の頭がつかえる。付箋は「話せないから」ではなく「話すと相手を待たせるから」書いている。吃音を治る・克服する話にはしない。最終話でも彼はつかえたまま話し、ひよりは待つ。
  - ひよりの唯一の取り柄は、才能ではなく「人の言葉を最後まで待てること」。第01話で前職の「おそい」と並べて植え、第02話で初対面の恭介に対して初めて効かせる。父の茂は逆に「先に言ってしまう人」で、対比にする。
  - フミの「手で渡して、一言そえる」が縦糸。付箋は手渡しの代わりであり、最終話で恭介が回覧板を手で渡して一言を言うことで回収する。
- **各話の到達点（恋愛の段）**：01 付箋の往復が始まる／02 初対面、つかえる言葉をひよりが待つ／03 付箋が業務連絡から私信になる／04 祭りの夜、恭介が吃音のことを自分の口で話し、ひよりは彼の声が好きだと気づく／05 それが恋だと自覚し、同時に「春に家を売る」期限が立つ／06 台風の夜、手をつなぐ。恭介が初めて「ひよりさん」と呼ぶ／07 恭介が工房に誘う。ひよりは東京からの誘いを黙っている／08 告白寸前で途切れる／09 東京の話を打ち明け、付箋の「おめでとうございます」ですれ違う／10 手渡しの一言。
- 既存作『湯を焚く音』と「仕事を失った女性が身内の家に来て、町の人と一年を過ごす」骨格が近い。あちらは家業（銭湯）の継承と常連客の人情が軸だが、本作は家業を継がず、町内会の班長という「誰がやってもいい役」を通した恋愛が軸。町の人の挿話は毎話、二人の距離を一段動かすための乗り物として置く。
- 祖母は施設ではなく娘宅に身を寄せている設定（『二度目のごはん』との重複回避）。電話口の掛け合い担当。
- 時刻・数・金額はすべて漢数字（七時十二分／三百円）。携帯の連絡手段は「メッセージ」と書き、アプリ名・英字は使わない。

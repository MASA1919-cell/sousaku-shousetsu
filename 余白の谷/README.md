# 余白の谷

### 見習い測図士と、地図から消された故郷の謎

## あらすじ

国の正式な地図「正図」に描かれた土地だけが、確かな形を保つ王国。王立測図学院の一年生ノエ・ハルシュ(十五歳)は、最新の北図を広げて凍りつく。故郷の谷があるはずの場所が、真っ白な余白になっていた。欄外には「区画十七、抹消。担当測図官エダ・ハルシュ」——ノエの姉の名前。地図から消された土地は霧に沈み、人々はその名を忘れていく。言い伝えでは、百日で名はこの世から消え、二度と描き戻せなくなる。抹消から五十八日目。友人も郵便局も、谷の名をもう覚えていない。なぜ姉は、二百十四人の暮らす村を消したのか。歩幅、三角形の内角、川の水位——測図の数字だけを手がかりに、ノエは首席の先輩シオンと、残り四十二日の謎に挑む。

## 登場人物

- **ノエ・ハルシュ** — 主人公・語り手。十五歳、王立測図学院一年の奨学生。北の山あいのリンデ谷の生まれ。歩幅は七十一センチ(十二歳の夏は六十二センチ)。谷に生まれた者は谷の名を長く覚えていられるため、王都でただ一人、故郷の名を手放さずにいる
- **シオン・ヴァルデン** — 十七歳、学院三年の首席。口癖は「数字が合わないものは気持ちが悪い」。測図院副院長の一人息子で、院の書庫で育った。角度の読みが正確
- **エダ・ハルシュ** — ノエの姉。二十四歳の測図官。歩幅七十八センチ。正図室の夜番の晩に国王の大印を使い、区画十七を正図から消して姿を消した。数字の七に横棒を入れ、署名の最後の一画を止める字の癖がある
- **グレン老師** — 学院の老教授。七十代、目が見えないが足音で歩数を言い当てる。六十年前、抹消された村の名を思い出せず描き戻せなかった過去を持つ
- **オルグ・ヴァルデン** — 測図院副院長で学院理事。王都の灯石が尽きかけていることを理由に、灰鉄商会と組んでリンデ谷の無人地認定を進めた
- **ゴドー** — 灰鉄商会の会頭。王都の灯石の半分を扱う
- **ミーナ** — ノエの寮の同室で同じ組。明るく、役所の書類に詳しい。谷の名を聞いてもすぐ忘れてしまう
- **ハンナ** — ノエとエダの母。リンデ村で羊を飼い、水車小屋で粉を挽く
- **トマ/リタ** — ノエの幼なじみの兄妹
- **オスカ爺** — リンデ村の村長。「谷は自分たちの足で測って拓いた土地」と移住を断った
- **ベルタ** — 水車小屋のおばさん

## 制作メモ

- 異世界ファンタジー×十代の学生×謎解き×シリアスから希望へ。**本作の謎は魔法の決まりそのものを、フェアに解けるルールとして使う**。正図に描かれた土地だけが「在る」、抹消地の名は記憶と文字から薄れる(およそ百日)、霧は名を呼ぶ者だけを通す、の三つ
- **決定的な手がかりは、必ず測量の数字か地図の読み**で統一した(歩幅六十二センチ/川の水位/受付簿と公報/三角形の百八十一度/通知の日付/水図に残った川の名)。既存の『さよならの部屋』は「失踪した姉」が縦糸で共通するが、あちらの手がかりは遺品、本作は数字と地図。『左手の署名』と同じく毎話の終わりで前提が一つ覆る構成だが、本作は書類の読みではなく測図の検算で覆す
- 数値は全話で固定:外周一万九千五百三十メートル=十二歳で三万千五百歩(歩幅六十二センチ)/十五歳で二万七千五百七歩(歩幅七十一センチ)/エダなら約二万五千歩(七十八センチ)。無人調書の三角形は六十二度十四分+七十一度三十分+四十七度十六分で、度だけ足すと百八十、分の六十分を繰り上げると百八十一度。谷ほどの大きさなら球面の余りは一秒未満なので、まるまる一度の超過はありえない
- 伏線と回収:歩幅(1話)→3話/「分まで足す」(1話)→6話/土図と水図の二枚重ね・「川は嘘をつかない」(1〜2話)→7〜8話/抹消地の私文書の禁止(2話)→7話/免状は審図会でしか剥げない・助手一名(3話)→9〜10話/縁者の異議申し立て・期間は抹消中止まる(4話)→10話/奨学金の再審査(1話)→6話
- 日数:抹消から五十八日目に始まり、九十九日目の審図会で描き戻し、百日目の朝に霧が晴れる
- 姉は谷を守ったが、大印の盗用と手簿の偽造の罪は消えない(免状取り上げ+北部州で三年の無給測量)。灯石の問題も「谷の人と話して決める」余地を残すだけで、きれいには解決しない。それでも名前は書き戻され、途切れた道はつながる

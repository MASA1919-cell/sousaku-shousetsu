# 第2話「川は嘘をつかない」

翌朝、学院長室に呼ばれた。
長椅子に、見知らぬ男が座っていた。灰色の髪をきっちりと撫でつけ、襟には測図院の銀の徽章。学院長が、ずいぶん丁寧に頭を下げている。
「測図院副院長の、オルグ・ヴァルデン殿だ」
「ノエ・ハルシュさん、ですね」副院長は穏やかに微笑んだ。「お姉さんのことで、少しお話を」
姉は、大印を盗用した罪で手配されている——副院長は静かにそう告げた。
「抹消の夜、エダ・ハルシュは正図室の夜番でした。正図室には国王の大印が保管されています。彼女はその大印を勝手に使い、院の承認のないまま、区画十七を正図から消した。そしてその夜のうちに、王都から姿を消しました」
「区画十七、じゃありません」私は言った。声が震えた。「リンデです。私の村です」
副院長は少しだけ目を細めた。
「ええ。その名は、もう記録の上ではほとんど読めなくなっていますがね」
「姉はどこにいるんですか」
「それを、あなたに伺いたかった」
知らない、と答えるしかなかった。本当に知らなかった。副院長は手帳に何かを書きつけ、立ち上がった。
「お姉さんから連絡があれば、必ず院へ。それから——抹消された土地の記録を、私的に持ち続けることは法で禁じられています。故郷を想う気持ちは分かりますが、どうか、お気をつけて」
扉が閉まったあとも、私はしばらく動けなかった。上着の内側で、手帳が心臓みたいに重かった。
　◇
昼休み、私は北棟の一番奥の部屋を叩いた。グレン老師の研究室だ。
「抹消のことを、教えてください」
老師は窓辺の椅子から顔を上げなかった。長い沈黙のあとで、ぽつりと言った。
「座りなさい。昔話をしてやる」
六十年前、老師がまだ若い測図官だったころ。北の山あいに、治水のため湖に沈めることになった村があった。村人を移したあと、規則どおり、その土地は正図から抹消された。
「だが、湖の計画は流れた。工事は始まらなかった。土地は湖にならず、ただ霧に沈んだまま残った。描き戻そうという話になったのは、抹消から四か月もたってからだ」
「描き戻せなかったんですか」
「書けなかったのだ。村の名前が」
老師の声は乾いていた。
「抹消された土地の名は、人の記憶から薄れていく。書いた文字からもだ。インクは、ひと月もすれば灰色の染みになる。正図の欄外も、役所の台帳も、みな同じだ。だから院の書類は、抹消地を区画の番号でしか呼ばない」
「人の名前は、どうなるんですか。そこに住んでいた人の」
「紙に書いた人の名は残る。だが、土地の名が薄れるにつれて、外の者はその名が誰のものだったのか、結びつけられなくなる。字は読めても、顔が浮かばなくなるのだ」
老師は指先で机の縁をなぞった。
「それから、正図の地名は、その名を覚えている者が書かねば紙に乗らん。古い台帳の字をなぞって写しても、インクが紙の上を滑って落ちる。わしはそれも試した」
「でも、覚えている人がいれば」
「わしも覚えているつもりだった。村の名を何百回も口にした。それでも、ある朝、出てこなくなった。言い伝えでは、およそ百日。百日で、名はこの世から消える。名の書けない土地は、正図に描き戻せない。あの村は今も、北図の隅で白い染みのままだ」
百日。リンデが消されて、今日で五十九日目だ。
「その土地に生まれた者は、ほかの者より長く名を覚えている、とも言われる。お前が覚えているのは、そのせいだろう。……それでも、百日は百日だ」
「霧の中には、入れないんですか」
「陸からは無理だ。霧に向かって歩けば、いつのまにか入ったところへ戻される。ただ——」
老師は少し言いよどんだ。
「言い伝えでは、霧は、名を呼ぶ者だけを通すという。あの村のときも、名を覚えていた婆さまが一人、霧の中へ入っていった。帰っては来なかったがな」
窓の外で、鐘が午後の講義を告げた。老師は最後に、ほとんど独り言のように言った。
「エダ・ハルシュは、わしの教え子の中でいちばん地図を大事にした娘だった。あれが理由もなく線を消すとは、わしには思えん」
　◇
講義のあと、私は王都の中央郵便局へ走った。
母に手紙を書いたのだ。元気ですか、手紙が来ないので心配しています、姉さんから何か聞いていますか。宛名には、何年も書いてきた住所を丁寧に書いた。北部州、リンデ谷、リンデ村、ハルシュ方。
窓口の局員は、封筒を受け取るなり台帳をめくり、気の毒そうに首を振った。
「この宛先へは、お届けできません」
「どうしてですか。北の、峠町の先の村です」
「峠町の先は、正図の上では何もない区画になっています。配達人は、地図にない土地へは行けないんですよ。行こうとしても、霧で戻されてしまう」
局員は封筒を私に返した。その手つきは、まるで中身のない紙を扱うようだった。
「それに、ほら」
言われて封筒を見た。今しがた書いたばかりの宛名の「リンデ」の文字だけが、ほかの文字よりわずかに淡く見えた。インクが乾ききる前から、もう薄れはじめている。
私は封筒を胸に抱えて郵便局を出た。王都の大通りは、いつもと同じように人であふれていた。誰ひとり、北の谷のことなんか気にしていない。私の村は、二百十四人ごと、この国の誰の心からも、静かに抜け落ちようとしていた。
　◇
その夜、手帳を開いて、息が止まった。
昨夜書いたばかりの「リンデ」の文字が、ほんの少しだけ、薄くなっていた。気のせいだと思いたかった。でも、ほかの頁の授業の書きつけと見比べると、はっきり色が違う。
私は同じ名前を、上からもう一度なぞった。母さん、ハンナ。トマ。リタ。オスカ爺。ベルタおばさん。毎晩こうして書き直せば、ひと月で消えるインクにも負けない。
書き終えると、私は寮を抜け出した。
図書室の夜間閲覧には、学年ごとに当番がいる。今夜は三年生の番だった。扉を開けると、ランプの下で、背の高い男子学生が地図を広げていた。
銀縁の眼鏡。三年の首席、シオン。新入生の歓迎会で「感傷で地図は読めない」と挨拶して、一年生をまとめて凍りつかせた人だ。
「閉館まで半刻だ」と彼は顔も上げずに言った。「何を見に来た」
「第四北図の、水図です」
シオンの手が止まった。彼が広げていたのも、まさにそれだった。
正図は二枚重ねでできている。土地を描く土図と、川や湖を描く水図。土図は測図院が、水図は水利院が受け持ち、二枚を重ねて一枚の正図として刷る。抹消の欄外を見たとき、私は土図のことしか考えていなかった。
「……座れ」
シオンが場所を空けた。私は彼の隣に立って、水図を覗き込んだ。
青い線が、白い余白の中を貫いていた。
土図では何もない雪原のような区画十七を、一本の川が北から南へ流れている。土地は消されても、川は消されていない。川の名前の欄も、灰色の染みにはなっていなかった。
「リンデ川」
私が読み上げると、シオンが眉を上げた。
「読めるのか。土図の欄外は、もう染みになっていたが」
「土地の名前と、川の名前は別なんです。川は抹消されていないから」
「なるほど」シオンは別の帳面を引き寄せた。水利院の水位記録だった。「峠町の水位標だ。リンデ川がこの区画から出てきたところにある。この六十日、水位は平年と変わらない」
「それって……」
「この川の水源は、ほとんどが区画十七の中だ。ほかに流れ込むのは細い沢がひとつだけ。もし区画十七が本当に無くなったのなら、川は干上がるはずだ。だが、水は来ている。平年と同じだけ」
シオンは眼鏡を押し上げて、白い余白を指で叩いた。
「消されたのは、地図の上の線だけだ。谷そのものは、霧の向こうでまだ水を集めている」
川は嘘をつかない。迷ったら、水を見なさい。
姉の声が、耳の奥でした。
私は白い余白の中を流れる青い線を、指でたどった。上流へ、上流へ。その先にある谷の底で、水車小屋の水車が回っている気がした。
「……どうして、先輩もこれを見ていたんですか」
「数字が合わないものは、気持ちが悪い。それだけだ」
シオンはそっけなく言って、地図を巻き取った。
村は、まだ在る。
霧の向こうで、二百十四人の暮らす谷は、まだ息をしている。

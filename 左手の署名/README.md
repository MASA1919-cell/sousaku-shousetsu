# 左手の署名

### 二十二年前に消えた妹を、司法書士事務所の二人が紙と足で探す

## あらすじ

茶の町・狭霧市。駅前の雑居ビル二階にある橘司法書士事務所は、探偵ではないが、人を探す。探すのは、紙の上にいる人だ。補助者の真壁澪(まかべ みお)、二十七歳。元市役所戸籍係で、住民票を職権で消す仕事に耐えられず役所を辞めた、書類を読む人。所長の橘宗一郎(たちばな そういちろう)、六十一歳。元家庭裁判所調査官で、番茶しか飲まず、人の話を聞くのが仕事だった、人を読む人。ある春の朝、二人のもとに、製茶業を営んでいた父を亡くした小柳依子(旧姓桐生)が訪れる。父の公正証書遺言は、家と蔵を、二十二年前に家出したきりの妹・菜穂に遺すと書いていた。妹は生きているのか。澪が戸籍の附票を引くと、二十二年誰にも見つからなかったはずの桐生菜穂は、たった一日で見つかった。三年前、東京の葛飾区に転入していたのだ。しかし、葛飾で会った「桐生菜穂」がボールペンを受け取ったのは、右手だった。依子が言うには、妹は左利きのはずなのに。保険証も戸籍も本物なのに、その人は誰なのか。本物の菜穂はどこにいるのか。紙の上では正しいことと、紙に書いていないことの間で、一話ごとに前提がひっくり返る長編ミステリ。二人組の司法書士事務所が辿り着くのは、二十二年前に交わされた「名前の交換」と、父が遺言の付言に残した一行の意味だった。全10話。

## 登場人物

- **真壁澪(まかべ みお)** — 語り手。二十七歳。橘司法書士事務所の補助者。元狭霧市役所戸籍係。戸籍・附票・住民票を読む「紙の人」。職権消除で消した人が実は生きていたことを、今も抱えている
- **橘宗一郎(たちばな そういちろう)** — 所長。六十一歳の司法書士。元家庭裁判所調査官(二十五年)。番茶を大きな湯呑みで日に六杯。人を追いかけず、待つ。「紙には、書いていないことがある」が口癖の「足の人」
- **小柳依子(こやなぎ よりこ)** — 依頼人。四十八歳。旧姓桐生。父の遺言どおり、妹に家を渡したいと願う。葬儀の朝に「変なこと」を見ている
- **桐生菜穂(きりゅう なほ)** — 依子の二つ下の妹。二十二年前、二十四歳で家を出た。左利き。父の合組(茶の配合)を継げる鼻を持つ。父に「渋いな」と言われるのが好きだった
- **佐伯千代(さえき ちよ)** — 二十二年前、暴力から逃げるために菜穂と名前を交換した女性。東京・葛飾の製本所で「桐生菜穂」として二十年働いてきた
- **桐生徹(きりゅう とおる)** — 依子と菜穂の父。桐生製茶の主。七十八歳で死去。六年前に脳梗塞で右手が動かなくなった。遺言の付言に一行だけ残した
- **小柳晴彦(こやなぎ はるひこ)** — 依子の夫。不動産業。失踪宣告で片付けるべきだと主張する
- **岡部** — 狭霧市民病院の元婦長。二十二年前の菜穂を覚えている
- **日下部良樹(くさかべ よしき)** — 二十二年前、千代を殴っていた男。十二年前に獄中で病死

## 制作メモ

- 全15作に続く16作目。ミステリ・サスペンス×二人組バディ×謎解き・どんでん返し。過去のミステリ2作(『さよならの部屋』=遺品連作、『動かなかった証拠』=法廷)とも、バディもの『二度目のごはん』(一話一件の連作)とも骨格を変え、**本プロジェクト初の「一本筋の長編ミステリ」**として、一つの依頼を10話かけて追う。毎話のラストで前提が一つひっくり返る構成(見つかった→左利きでない→妹ではない→殺していない→名前を交換した→蔵の帳面の字→ヘルパーの名前→月命日→返せない→二人とも菜穂)
- バディの役割分担は「紙を読む人(澪=戸籍・附票・住民票)」と「人を読む人(橘=聞く・歩く・待つ)」。決定的な手がかりは、紙(附票・合組帳・付言)と足(病院・事業所・墓)を交互に置き、どちらか一方では辿り着けないように組んだ。橘の「二人で行く。一人は黙っていられる」が全体の型
- 司法書士の職務上請求の範囲(相続に必要な戸籍しか取れない)を、単なる制約ではなくミステリのルールとして使った。佐伯千代の住民票を「取れば一発で分かるのに取らない」ことで、足の捜索と「待つ」解決(月命日)に必然性を持たせている
- フェアプレイの手がかり: ①第1話の付言「茶は、お前の淹れ方でいい」 ②第1話の「妹は左利き」と第2話の右手の受け取り ③第4話の岡部の「渋いと言うと嬉しそうな顔をした」と第6話の「父は佐伯さんの茶に渋いなと言った」 ④第3話の母の子守歌と第6話の斎場の女 ⑤第1話で依子が何気なく口にする「ヘルパーの佐伯さん」が第7話で意味を変える
- 法律まわりは、戸籍自体は一度も動いていない(動いたのは住民票と暮らし)という整理にし、名の変更(戸籍法)の「長年使用した通称」を最終話の着地に使った。断定的な法的助言にならないよう、橘に「司法書士であって弁護士ではない」と言わせている
- 結末は、名前を返す/もらうの二段構え。千代が「千代には戻れない」と言う第9話ラストのどんでん返しを、第10話で「佐伯菜穂」に変えることで解く。二人とも菜穂でいい、父は「渋いな」としか言わないから、が全体の答え

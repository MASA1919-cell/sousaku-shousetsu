# 一手ぶん、上へ

### 百四十六センチのクライマー

## あらすじ

柊すずは、身長百四十六センチ。部費も道具代も出せない母子家庭の高校一年生で、才能も後ろ盾も、何ひとつ持っていない。ある夕方、通学路の廃工場から人の落ちる音を聞いて忍び込んだすずは、鋳物工場の高い壁いちめんに人工のホールドが埋め込まれた、素人手づくりのボルダリング壁と出会う。壁の主は、二十年前に肩を壊して競技をやめた元選手・黒木巽。彼は誰にも何も教えない。「教えることはない。壁が全部言ってる」——それだけを言って、すずが登るのを黙って見ている。六級で落ち、五級で観察を覚え、四級で指の皮を剥き、借り物の靴が破れて足踏みし、自分で稼いだ一足で三級へ。積み上げの単位は、いつも一手ぶんだけ。そして工場の最上部には、二十年前から誰も落としていない一本が残っている。名前も等級もつけられていない課題、通称「無名」。最後の一手が、どうしようもなく遠い。背の低さを言い訳にせず、足で高さを作る方法を自分で組み立てたすずが、全国への切符と、二十年ぶんの「無名」に手を伸ばす、積み上げの青春クライミング小説。

## 登場人物

- **柊すず（ひいらぎ すず）** — 主人公。高校一年、身長百四十六センチ。母とふたり暮らしで、部費も道具代も出せない。負けん気と、諦めの悪さだけを持っている。壁の前ではよく黙る。
- **黒木巽（くろき たつみ）** — 三十八歳。廃業した鋳物工場「黒木鋳造」の跡取り。二十歳で国内屈指のクライマーだったが右肩の腱を壊して引退。工場の壁にひとりでホールドを打ち、誰にも何も教えない。口癖は「壁が全部言ってる」。
- **大鳥颯太（おおとり そうた）** — 高校一年、身長百八十三センチ。膝の故障でバスケットボールをやめた。リーチだけで簡単に登れてしまうため、伸び方を知らない。
- **真砂かえで（まさご かえで）** — 高校一年。人が登るのを見て記録するのが好き。手数と秒数と落ちた位置をノートに書き溜め、すずの積み上げを目に見えるかたちにする。
- **鹿沼環（かぬま たまき）** — 高校一年。県内強豪ジム「登攀館」所属で全国常連。恵まれた環境で正しく強くなった選手。すずを見下さないぶん、いちばん残酷な言葉を持っている。
- **柊郁子（ひいらぎ いくこ）** — すずの母。病院の夜勤で働く。娘が何かに夢中になるのを、少し怖がりながら見ている。
- **梶原源治（かじわら げんじ）** — 黒木鋳造の元工員。八十歳。鋳型を高い所へ運んだ昔の工員の身体の使い方を知っている。

## 制作メモ

- ジャンル：スポーツ／勝負の青春（本プロジェクト初）／主人公：何も持たない少年少女／メイン軸：積み上げ型の成り上がり／トーン：爽快なハッピーエンド／全10話。
- 積み上げの単位は日本のボルダリング段級グレード（六級→五級→四級→三級→二級→一級→初段）。等級が漢数字で書けるため、本文に英字を混ぜずに「数字が伸びる快感」を出せる。
- 十話それぞれで「上がる理由」を別の種類にした（意志／観察／保持力／道具／技術／仲間の情報／精神）。第04話と第06話は状況が悪化して終わる話で、最終話の爽快さはその二話の借りを返すためにある。
- 黒木巽は師匠役ではなく「教えない大人」。方法はすず自身が組み立てる。既存作『風を読む仕事』のベテラン観測員（教える師匠）と構造が重ならないようにした。
- 縦軸は課題「無名」。第01話で壁に存在だけを見せ、第08話で正面から挑み、最終話で完登する。
